# English for IT

Offline-first English learning app for IT professionals, built with React + TypeScript + Vite.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Current prototype

Responsive Web UI, four course catalogs, eight-question Daily Standup lesson, vocabulary flashcards, and localStorage progress.

**Not yet implemented:** full PWA offline caching, audio lessons, Android packaging, and remaining course lessons. Build verification is pending.
